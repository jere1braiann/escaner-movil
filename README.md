# escaner-movil

Aplicación móvil desarrollada con React Native y Expo para escaneo y desbloqueo.

## Características

- Escaneo y captura mediante cámara con `expo-camera`.
- Integración para lectura y procesamiento de imágenes.
- Navegación y estructura basada en Expo Router.

## Instalación y Uso

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Configurar variables de entorno:
   Crear un archivo `.env` en la raíz del proyecto:
   ```env
   EXPO_PUBLIC_GEMINI_API_KEY=tu_api_key_aqui
   ```

3. Iniciar la aplicación:
   ```bash
   npm run start
   ```
